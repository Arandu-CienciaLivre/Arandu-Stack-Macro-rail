# Arandu Stack Macro Rail

Trilho motorizado de precisão para macrofotografia e focus stacking, desenvolvido como uma plataforma aberta, acessível e de baixo custo.

**Autor:** Pedro José Vieira de Souza

## Sobre o projeto

O Arandu Stack Macro Rail é um sistema motorizado de deslocamento de câmera voltado para macrofotografia, focus stacking e aplicações que exigem movimentos lineares precisos e repetíveis.

O projeto faz parte da proposta Arandu de desenvolver ferramentas científicas abertas, acessíveis e reproduzíveis.
