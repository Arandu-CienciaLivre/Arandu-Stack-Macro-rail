# Firmware

[Português](#português) | [English](#english)

## Português

Esta pasta contém o firmware oficial do **Arandu Stack Macro Rail**.

O firmware é responsável pelo controle de movimento do trilho, interface com o usuário, configuração dos parâmetros de operação e automação das sequências fotográficas.

### Versão atual

**v1.0.0**

Esta versão corresponde à primeira versão estável publicada do firmware.
